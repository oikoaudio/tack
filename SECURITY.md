# Security policy

Report a vulnerability privately through [GitHub's private vulnerability reporting](https://github.com/oikoaudio/tack/security/advisories/new). Do not open a public issue for it. Include the plugin, version, host, operating system and the steps that trigger the problem. A crafted kit file or project state that crashes a host or runs code counts as a vulnerability.

Only the latest release gets fixes. Tack is in beta, so a fix ships in a new release rather than as a patch to an older one.

Builds are not signed, and macOS builds are not notarized. Download them only from this repository's releases, and check them against the release's `SHA256SUMS`.
