Pages press again: next screen

HOME
Overview: all seven lanes and the patterns. K1–K4 are the voice's pitch, filter, decay, volume.
SEQ
One voice in detail: the bars view, again for the note view.
EDIT ENV LFO
The voice's sound, three rows of four. The dials work the middle row. EDIT has two screens.
OCT+ / OCT- held
On a sound page: the dials reach the top or bottom row.
FX
Black keys send voices to the FX. Type, mix, two settings; OCT- held for the rest.
GLO
Mixer, then settings, then mixer again.NEW
ARP
The selected lane: its Lane, Euclid and Vel shape screens in turn.
SEL held 1 s
What SEL does on this page.

Steps and locks

white key
Set or clear a step, on release.
OCT- / OCT+
Show the bar before or after.
step held + K1–K4
Lock those values on the step, up to eight.
step held + ALGORITHM
Nudge, in 24ths of a step.
step held + PRESETS
Chance.
step held + SELECT
Recurrence, a cycle of 1–8 passes; black keys 1–8 pick the passes it plays.
step held + EDIT
Clear the step's locks.

Lanes

SEL + white key
That step is the lane's last. A voice key held does the same.
SEL + OCT+ / OCT-
A bar more or less. A new bar copies the one before.
SEL + EDIT 1 s
Clear the lane.
ARP Lane
K1 length · K2 direction · K3 speed · K4 start. ALGORITHM nudges the lane.
ARP Euclid
K1 length · K2 hits · K3 rotation · K4 puts the lane back.
ARP Vel shape
K1 rhythm · K2 centre · K3 amount · K4 shifts it later. Off restores.

Voices and mixer

voice key
Select the voice and play it.
ARP + voice key
Mute or unmute.
SEQ + voice key
Select without playing.
ROLL held
Roll the selected voice. Rate on GLO's settings, OCT- held.
GLO mixer
Strips with level, meter and pan. K1 level · K2 pan · K3 FX send · K4 drive.NEW
SEL + voice key
On the mixer: solo, and again to lift it. Not saved.NEW
GLO settings
K1 tempo · K2 shuffle · K3 rate · K4 bits. OCT- held: USB audio, MIDI clock, preview, roll rate.

Patterns and song

SEQ + white key
Pattern 1–16. Running, it changes at the end of the longest lane.
SEQ + several
A chain, which loops until you pick one pattern.
COPY + white key
Copy this pattern onto that one.
SEQ + ARP
The song: white keys fill the rows. K1 row · K2 pattern or end · K3 repeat ×1–16, or stop / loop on the end row · K4 song on.NEW
SEL + K1
On the song page: right copies the row, left removes it.NEW
COPY tapped
On the song page: the playing chain into the rows.

Kits

PRESETS
Step through the bank. Back past the first: the init kit.
SEL + PRESETS
Mutate the kit. Turning back retraces the walk.
SEL + ALGORITHM
Mutate the selected voice.
SEL + HOME 1 s
Reload the kit as the pattern was last saved.NEW

Frankensound MONO

A kit made from up to four, a section of each voice from each. It is your kit: edit and save it as any other.

K1–K4
The parent kits: random, none, this kit or one from the bank. K1 starts on this kit and the rest on random, which draws a kit for each combo.NEW
PRESETS right
A new combo, heard at once.
voice key + PRESETS
A combo of that voice alone, the others as they are.
PRESETS left
Back through the combos. At 0, the kit from before.

Morph

Each pattern has a target of its own, and morph blends the kit towards it.

ALGORITHM
How far: kit at 0, target at 127. Also CC 1 on channel 1.
POLY + K1–K4
Set the target's value. The dials show the target while held.NEW
POLY + PRESETS
Copy a bank kit in as the target. NONE drops it.
SAVE, K4 blend
Keep what you hear as a kit in the bank.

Detail views SEQ

bars view
A key, SEL or SELECT picks a step. K1 velocity · K2 nudge · K3 flam · K4 chance.
note view
All 27 keys play the voice, F3 to G5; OCT moves them. K1 note · K2 velocity · K3 how hard keys write · K4 step on.
REC, note view
Keys write: stopped step by step, running live.

Play and save

PLAY · REC
Start and stop · live recording.
SELECT
Tempo. With SEL held: shuffle.
SAVE
Shows what it will save; again to write. K4 pattern, blend or kit · K1 or SELECT the slot.
SEL + SAVE
Write the changes at once.
MIDI in, ch 1
Notes 60–66 play the voices. Notes 0–15 or Program Change pick a pattern. MIDI clock: OCT- and K2 on GLO's settings.
